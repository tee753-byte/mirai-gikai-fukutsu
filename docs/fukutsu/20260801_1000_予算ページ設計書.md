> 作成日: 2026-08-01

> きっかけ: 福岡市版の「予算・評価・お金の使い道」セクションを参考に、福津市版でも「一般質問」の下に予算まとめを置きたいという要望

## 1. 目的

福津市の予算（特に令和8年度の「主要事業」）を、市民が読みやすい形でサイトに載せる。単なるPDFへのリンク集ではなく、**1事業＝1カード**の形にして、興味のある事業をパッと見つけられるようにする。

福岡市版に既にある「予算・評価・お金の使い道」を土台にしつつ、福津市が実際に公開している資料の形に合わせて作り直す（後述の通り、福岡市と福津市では資料の作られ方が違うため）。

### 「主要事業の概要」PDFの中身（実際に開いて確認済み）

目次（2ページ目）で、40件の事業が4つのグループに分かれている。

1. 災害に強く、安心して暮らせるまちづくり（14件）
2. 次世代を育む教育環境の整備（9件）
3. 人も企業も行政も「稼ぐ」まちづくり（4件）
4. その他（13件）

各事業は1ページの「調書」フォーマットで、以下が必ず載っている（3ページ目に凡例あり）。

- 事業名（見出し）／大事業名／担当課
- 一般会計（款・項・目）＝予算書の参照先
- 基本構想：テーマ別目標像・基本方針・分野別計画等（＝市の「まちづくり基本構想」7テーマのどれに該当するかのタグ）
- 前年度予算額／本年度予算額／財源内訳（国庫支出金・県支出金・繰入金・市債・その他特定財源・一般財源）
- 事業の目的・背景（文章）
- 事業の内容（文章。指標があれば記載。写真が入っていることもある）
- 事業費の内訳（科目ごとの金額）

> 補足: 巻末（41ページ）に事業実施位置図、45ページに「まちづくり基本構想 7つのテーマ別事業費」の一覧がある（今回は未確認、必要なら後で見る）。

## 3. 福岡市版との違い（重要）

既存コード（`web/src/features/budget-overview/`、テーブル `budget_overviews` / `budget_themes` / `budget_initiatives`）は**福岡市版の資料構造**を前提にしている。

| | 福岡市版 | 福津市版 |
|---|---|---|
| 単位 | 「局」ごとに資料が分かれる（教育委員会、経済観光文化局…） | 資料は1つ（主要事業の概要、40件フラット） |
| 階層 | 局 → テーマ（例:「福岡100の推進」）→ 個別事業 | 4グループ → 個別事業（グループの下にさらにテーマは無い） |
| バッジ | 新規／拡充／継続の区分がある | 今回確認した範囲では区分の記載なし（要再確認） |

**方針**: 新しいテーブルは作らず、既存の3テーブルを**意味を読み替えて流用**する。

| 既存テーブル | 福津市版での使い方 |
|---|---|
| `budget_overviews`（1件） | 「局」ではなく「一般会計」全体を1件として扱う。`department_name`=`"一般会計"`、`total_budget`=336億2,579万1千円、`source_url`=予算書PDF、`direction`=運営方針の要約 |
| `budget_themes`（4件） | PDF目次の4グループをそのままテーマとして登録 |
| `budget_initiatives`（40件） | 1事業＝1行。`badge`列は使わない（該当データが無いため） |

こうすることで、マイグレーション追加なしで進められる。ただし `department_name` という列名が実態と合わなくなる（「一般会計」は部署ではない）ため、違和感がある。**フェーズ2着手時に、列名はそのままで運用するか、コメントで補足するかを決める**（保留事項参照）。

## 4. ページ構成案

### 4-1. トップページの導線

現状の並び順（`web/src/app/(main)/page.tsx`）:

```
Hero → 本日の定例会 → [予算概要バナー(現在showBudget=falseで非表示)] → 一般質問バナー → 市長公約特集 → 議案一覧
```

要望どおり、**予算バナーを一般質問の下**に移動する。

```
Hero → 本日の定例会 → 一般質問バナー → 予算バナー(新規) → 市長公約特集 → 議案一覧
```

既存の `BudgetOverviewBanner`（`web/src/components/top/budget-overview-banner.tsx`）は福岡市版の文言・データ形状にべったりなので、**作り直すか、大きく手を入れる**前提。

### 4-2. `/budget` 概要ページ

- 総額（336億2,579万1千円）と前年度比
- 運営方針の要点（市長メッセージの要約、AIが読んで要約する場合は「AI要約」と明示）
- 3つの公式PDFへのリンク（予算書／運営方針／主要事業の概要）
- 4グループ（テーマ）のカード。クリックでそのテーマの事業一覧へ

### 4-3. テーマ別 事業一覧ページ（`/budget/[theme_slug]` など）

- そのテーマに属する事業カードを一覧表示

### 4-4. 事業カード（一覧での見た目）

ユーザーの要望「主要事業をカードにできたら面白い」の中心部分。1カードに載せる情報:

- 事業名（見出し）
- 本年度予算額（例: 「2,403万円」）。前年度比が分かるとなお良い（増減の矢印など）
- 担当課
- 事業の目的・背景 or 内容から1〜2文の要約（40件を人力で要約するかAI要約にするかは後述）

予算額の桁が事業ごとに大きく違う（数十万円〜数十億円）ため、金額の見せ方（棒グラフ的な視覚表現を入れるか、数字だけでよいか）はUIデザイン時に検討する。

### 4-5. 事業詳細ページ

- 目的・背景／内容／費用の内訳（表）をそのまま掲載
- 出典: 「主要事業の概要 P.◯◯」＋PDFへのリンク。PDFは `#page=N` を付けると多くのブラウザで該当ページへジャンプできる（例: `.../R8_syuyoujigyounogaiyou.pdf#page=4`）

## 5. データ作成方針

- **個人情報の心配は無い**: 議案書PDF（山本議員提供、再配布不可）とは別物で、福津市が自ら一般公開しているPDF。人事情報も含まれない（担当課名のみ）。CLAUDE.mdの「個人情報を含みうるものはコミットしない」制約の対象外と判断できる
- **転記の方法**: 40件を毎回全部やろうとしない。他のデータ投入（会議録の議案化など）と同じく、**まず数件で通しで動かす**方針を踏襲する
- **要約の作り方**: 「事業の目的・背景」「事業の内容」の原文をそのまま載せるか、短く要約するかを決める必要がある。要約する場合はAI要約である旨を明示し、事実（目的・金額・内容）のみを抜き出し、評価コメントは書かない（他の議案要約と同じ方針）

---

## 6. 中立性・表示上の注意

- 「福津市の公式情報ではない」旨は他ページ同様に表示する
- 事業の取捨選択をしない（40件全部が対象。人が「注目事業」を選ぶ場合は選定基準を明記する。市長公約特集で決めた「機械的基準を優先」の考え方に合わせる）
- 予算額の増減について論評しない（「増えた／減った」という事実だけを書き、良し悪しの評価はしない）

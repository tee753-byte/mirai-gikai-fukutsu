# 独自ドメイン取得と一般公開の手順書

作成日: 2026年8月1日

いま「みらい議会＠福津市」は、Basic認証（IDとパスワードを知っている人だけが見られる状態）で山本議員に限定公開しています。
このドキュメントは、そこから **独自ドメインを取って、誰でも見られる状態にする** までの手順をまとめたものです。

初めての人でも迷わないように、専門用語には都度説明をつけています。

## 1. ドメイン名を決める

### ドメインとは

いまサイトのアドレスは `mirai-gikai-fukutsu-web.vercel.app` です。
この `〜.vercel.app` の部分は、Vercel（サイトを動かしているサービス）が無料で貸してくれている住所です。

独自ドメインを取ると、これを `example.jp` のような**自分の住所**に変えられます。

### なぜ取ったほうがよいか

1. **信頼されやすい**。`〜.vercel.app` のままだと、SNSで共有されたときに「怪しいサイトかも」と思われることがあります
2. **住所が変わらない**。将来Vercel以外に引っ越しても、同じアドレスを使い続けられます
3. **覚えてもらえる**。チラシや名刺に書けます

### 名前を決めるときの注意（重要）

**公式サイトと間違われる名前は避けてください。**

福津市の公式サイトは `city.fukutsu.lg.jp` です。`lg.jp` は地方公共団体しか取れないドメインなので、そもそも取得できませんが、それ以外でも「市の公式サイトだ」と誤解される名前は避けるべきです。

| 評価 | 例 | 理由 |
| --- | --- | --- |
| ◎ おすすめ | `mirai-gikai-fukutsu.jp`<br>`mirai-gikai-fukutsu.com` | 「みらい議会」が入っていて、非公式サイトだと分かる |
| ○ 可 | `fukutsu-gikai.net` | 田川市版（`tagawa-gikai.jp`）と同じ考え方。ただし公式と誤解される余地はある |
| △ 避ける | `fukutsu-city.jp`<br>`fukutsu.jp` | 市そのものを名乗っているように見える |

**迷ったら `mirai-gikai-fukutsu.jp` をおすすめします。** 「みらい議会」というシリーズ名が入るので、福岡県版・田川市版とのつながりも分かります。

### 末尾（.jp / .com など）の選び方

| 末尾 | 年額の目安 | 特徴 |
| --- | --- | --- |
| `.jp` | 2,000〜4,000円 | 日本の組織・個人しか取れない。信頼感がある |
| `.com` | 1,000〜2,000円 | 世界で一番使われている。安い |
| `.net` | 1,000〜2,000円 | `.com` が取れないときの代替 |

**市民向けのサイトなので `.jp` をおすすめします。** 少し高いですが、年に数千円の差です。

## 2. ドメインを買う

### どこで買うか

日本語で使えて、初心者にも分かりやすいところを挙げます。

| サービス | 特徴 |
| --- | --- |
| **お名前.com** | 国内最大手。安いが、申し込み時にオプションのチェックが最初から入っていることが多いので注意 |
| **ムームードメイン** | 画面が分かりやすい。初心者向け |
| **Cloudflare Registrar** | 原価で売っているので最安。ただし画面が英語 |

**初めてなら「ムームードメイン」をおすすめします。** 余計なオプションを勧めてこないので、迷いにくいです。

### 買うときの手順

1. サービスのサイトで、決めたドメイン名を検索する
2. 「取得できます」と出たらカートに入れる
3. **オプションは基本すべて外す**（後述）
4. 支払って完了

### オプションについて

申し込み画面でいろいろ勧められますが、**必要なのは1つだけ**です。

| オプション | どうするか |
| --- | --- |
| **Whois代行（whois情報公開代行）** | **必ずONにする。無料のことが多い** |
| SSL証明書 | **不要**。Vercelが無料で自動でつけてくれます |
| レンタルサーバー | **不要**。Vercelを使うので |
| メールサービス | **不要**（サイトにメールアドレスは載せていないため） |

**Whois代行だけは必ずONにしてください。**
ドメインの所有者情報（氏名・住所・電話番号）は、誰でも検索できる公開情報になります。Whois代行をONにすると、**あなたの個人情報の代わりに業者の情報が表示されます**。個人でドメインを取る場合は必須です。

### 自動更新について

**ONにしておいてください。** 更新を忘れるとドメインが失効し、**第三者に取られて全く別のサイトにされる**ことがあります。市議会情報を扱うサイトでこれが起きると被害が大きいです。

## 3. Vercelにドメインをつなぐ

買っただけでは、まだサイトは表示されません。「このドメインに来た人を、Vercelのサイトに案内する」設定が必要です。

### 3-1. Vercel側でドメインを登録する

1. https://vercel.com/ にログイン
2. `mirai-gikai-fukutsu-web` プロジェクトを開く
3. 上のタブから **Settings** → 左メニューの **Domains**
4. 入力欄に買ったドメイン（例: `mirai-gikai-fukutsu.jp`）を入れて **Add**
5. `www` をつけるか聞かれたら、**「www なし」を主、「www あり」は転送**を選ぶ（後から変えられます）

すると、**設定すべきDNSレコードが画面に表示されます。** この画面は開いたままにしてください。次で使います。

### 3-2. ドメイン側でDNSを設定する

DNSとは「このドメインに来たら、この場所に案内する」という電話帳のようなものです。

ドメインを買ったサービス（ムームードメインなど）にログインし、**「DNS設定」「ネームサーバー設定」「カスタム設定」**といった名前のページを開きます。

そこで、Vercelの画面に出ていた内容をそのまま登録します。ふつうは次の2つです。

| 種類 | ホスト名 | 値 |
| --- | --- | --- |
| A | （空欄 または `@`） | `76.76.21.21` |
| CNAME | `www` | `cname.vercel-dns.com` |

**Vercelの画面に出ている値を必ず優先してください。** 上の値は一般的な例で、変わることがあります。

### 3-3. 反映を待つ

DNSの設定は、世界中に伝わるまで時間がかかります。**早ければ10分、長いと24時間**です。

Vercelの Domains 画面で、ドメインの横が

- 🔴 **Invalid Configuration** → まだ反映されていない、または設定が違う
- 🟢 **Valid Configuration** → 完了

になれば成功です。SSL証明書（`https://` で見られるようにする鍵）はVercelが自動で取ってくれるので、何もしなくて大丈夫です。

**丸1日たっても🔴のままなら、DNSの入力内容を見直してください。** よくある間違いは、ホスト名に `@` ではなくドメイン名をそのまま書いてしまうことです。

## 4. 環境変数を直す（重要・忘れやすい）

### なぜ必要か

いまVercelには `NEXT_PUBLIC_WEB_URL` という設定が**登録されていません。**
（確認済み：Vercelに登録されているのは Supabase関連4つ、REVALIDATE_SECRET、BASIC_AUTH 2つの、計7つだけ）

この設定が無いと、プログラムは自動的に `http://localhost:3000`（自分のパソコン）を使ってしまいます。その結果、**次の2つが壊れます。**

1. **SNSで共有したときのカード画像が出ない**
   XやLINEにリンクを貼ると、ふつうはタイトルと画像が付いたカードが出ます。その画像のアドレスが `http://localhost:3000/ogp.jpg` になってしまい、**他の人のパソコンからは見えません。**
2. **ページの正しいアドレス情報が検索エンジンに伝わらない**

**見た目には何も問題が出ないのに壊れている**ので、忘れやすいところです。

### やり方

1. Vercel → プロジェクト → **Settings** → **Environment Variables**
2. **Add New** をクリック
3. 次のように入力する

| 項目 | 入れる値 |
| --- | --- |
| Key | `NEXT_PUBLIC_WEB_URL` |
| Value | `https://mirai-gikai-fukutsu.jp`（**買ったドメイン。末尾のスラッシュは付けない**） |
| Environments | **Production** にチェック |
| Sensitive | **チェックしない**（秘密情報ではないため） |

4. **Save**
5. **Deployments** タブ → 一番上の行の「…」→ **Redeploy** で反映

> **なぜ Redeploy が必要か**
> `NEXT_PUBLIC_` で始まる設定は、サイトを組み立てるときにプログラムの中に埋め込まれます。設定を変えただけでは反映されず、**組み立て直し（Redeploy）が必要**です。

## 5. コードを1か所直す（重要）

### なぜ必要か

`web/src/app/sitemap.ts` というファイルが、**サイトマップ**（検索エンジンに「このサイトにはこんなページがあります」と伝える一覧）を作っています。

このファイルは今、`VERCEL_URL` という値を使っています。これは Vercel が自動で入れる値ですが、中身は
`mirai-gikai-fukutsu-e3cdljgms-mirai-gikai-fukutsu.vercel.app`
のような**デプロイのたびに変わる長いアドレス**です。

独自ドメインを設定しても、**サイトマップだけが古い長いアドレスを指し続けます。**
これも見た目には分かりません。

### やり方

**Claudeに「サイトマップが独自ドメインを使うように直して」と頼んでください。** 手作業は不要です。

やる内容は「`VERCEL_URL` の代わりに、手順4で設定した `NEXT_PUBLIC_WEB_URL` を使うようにする」だけです。

### ついでにやっておくとよいこと

**`robots.txt` を置く**（検索エンジンへの案内文）。今はありません。

公開すると決めたなら、あったほうがよいです。これもClaudeに頼めます。

## 6. 公開前の最終チェック

**ここが一番大事です。** 技術的な作業より、こちらに時間をかけてください。

Basic認証がかかっている状態のまま、IDとパスワードを入れて、以下を一つずつ確認します。

### 6-1. 「非公式である」ことが伝わるか

- [ ] トップページに「福津市・福津市議会の公式サイトではありません」と出ているか
- [ ] フッターにも同じ表示があるか
- [ ] 議案の詳細ページを開いたとき、**そのページだけを見た人**にも非公式だと分かるか
      （SNSからは詳細ページに直接来る人が多いです）

### 6-2. AI要約の注意書きが出ているか

議案の「やさしい説明」はAIが書いています。

- [ ] 「AIがわかりやすく書き直したものです」と各ページに出ているか
- [ ] 免責事項に「AIによる要約・解説は不正確または誤解を招く内容を含む可能性があります」と書かれているか

### 6-3. 問い合わせ窓口が本当に動くか

- [ ] フッターの「運営者のtee」のリンクからGoogleフォームが開くか
- [ ] **実際に自分でテスト送信してみる**
- [ ] 送った内容が自分に届くか（Googleフォームの回答通知をONにしておく）

**ここは必ず実際に送ってください。** 誤りの指摘を受け取れないと、間違った情報が直せません。

### 6-4. 出典リンクが生きているか

- [ ] トピックスの各カードの出典リンクを全部クリックして、リンク切れがないか
- [ ] 議案詳細の「議決結果」のリンクが福津市のページに飛ぶか

### 6-5. 自分以外の人に見てもらう

**これが一番効きます。** できれば市政に詳しくない人がよいです。

見てもらうポイント:

- これが市の公式サイトだと思ったか
- どこか怒っているように読める部分はないか（中立性）
- 意味が分からない言葉はなかったか

### 6-6. 中立性の最終確認

- [ ] 特定の議員だけが目立っていないか
- [ ] トピックスで、賛成・反対の両方が載っているか
- [ ] 「事実」と「議員の意見」が分かれて書かれているか

## 7. Basic認証を外す＝公開

**ここまで終わってから実行してください。** これを実行した瞬間、誰でも見られるようになります。

### やり方

1. Vercel → **Settings** → **Environment Variables**
2. `BASIC_AUTH_USER` の行の「…」→ **Remove** → 確認して削除
3. `BASIC_AUTH_PASSWORD` も同じように削除
4. **Deployments** → 一番上の「…」→ **Redeploy**

> **仕組み**
> プログラムは「`BASIC_AUTH_USER` と `BASIC_AUTH_PASSWORD` の両方が設定されていたら認証をかける、無ければかけない」という作りになっています（`web/src/lib/basic-auth.ts`）。だから**消すだけで公開になります。**

### 公開後すぐに確認する

**シークレットウィンドウ**（Chromeなら Ctrl+Shift+N）で開いてください。ふつうのウィンドウだと、前に入れたパスワードが残っていて確認になりません。

- [ ] `https://（買ったドメイン）` がパスワードなしで開くか
- [ ] スマートフォンからも開くか
- [ ] XやLINEに自分宛てにリンクを送ってみて、**カード画像が出るか**（手順4の確認）

### もし問題が見つかったら

**すぐ非公開に戻せます。** 削除した2つの環境変数を登録し直して Redeploy するだけです。
パスワードは新しいものでかまいません。

## 8. 議会事務局への連絡（任意だが推奨）

義務ではありませんが、**やっておいたほうが安全**です。

後から「勝手にサイトを作られた」と受け取られるより、先に一言伝えておくほうが、その後の関係がずっと楽になります。

### 伝えるとよいこと

- 市議会の**公開情報のみ**を使った**非公式**のサイトであること
- 目的は市民に分かりやすく伝えることで、特定の議員や会派を応援するものではないこと
- 誤りがあれば直すので、指摘してほしいこと（問い合わせ窓口を伝える）
- 同様の事例が他にもあること（田川市版 https://tagawa-gikai.jp/ 、福岡県版、福岡市版）

### 伝えないほうがよいこと

- 山本議員から議案書PDFの提供を受けている点は、**触れる必要はありません**。サイトに載せているのは公開資料の情報だけで、PDFそのものは再配布していないためです。聞かれたら正直に答えれば問題ありません。

## 9. Xアカウント

### いつ作るか

**公開の1〜2週間前**がおすすめです。アカウントを作ってすぐ大量に投稿すると、スパムと判定されることがあります。

### アカウント名

**「非公式」を必ず入れてください。**

- 表示名: `みらい議会＠福津市（非公式）`
- ID: `@mirai_gikai_fkt` など

プロフィール欄には次を書きます。

```
福津市議会の議案・議決結果を分かりやすくまとめている非公式サイトです。
福津市・福津市議会の公式アカウントではありません。
政党「チームみらい」の公式でもありません。
誤りのご指摘はこちら → （Googleフォームのリンク）
```

### 何を投稿するか

**トピックスの見出しがそのまま使えます。** 今作ってある見出しは、意図的に「事実だけの一文」にしてあります。

```
公共施設の使用料を見直す条例改正5件が、いずれも否決されました。
くわしく → https://（ドメイン）/topics#koukyou-shisetsu-shiyouryou
```

### 投稿のルールを先に決めておく

**Xは中立性が崩れやすい場所です。** 140字に収めようとすると、どうしても書き手の判断が入ります。

先に決めておくとよいルール:

1. **議決結果と市の答弁だけを投稿する。** 議員の討論内容は投稿せず、サイトへ誘導する
2. **他アカウントへの反論・引用批判はしない**
3. **投稿は必ずサイトのページとセットにする**（出典を確認できるようにする）
4. 迷ったら投稿しない

## 付録C：この手順書で出てくる用語

| 用語 | 意味 |
| --- | --- |
| **ドメイン** | サイトの住所（`example.jp` のような文字列） |
| **DNS** | ドメインと実際のサーバーを結びつける電話帳のような仕組み |
| **SSL / https** | 通信を暗号化する仕組み。今はこれが無いと「危険なサイト」と表示される |
| **環境変数** | プログラムの外側から渡す設定。パスワードなど、コードに書きたくない値を入れる |
| **デプロイ / Redeploy** | プログラムを組み立てて、公開できる状態にすること |
| **Basic認証** | ブラウザにID・パスワードを聞かせる、最も簡単な鍵のかけ方 |
| **サイトマップ** | サイト内のページ一覧。検索エンジンに読ませるためのもの |
| **Whois** | ドメインの所有者情報を誰でも調べられる仕組み |

## 補足：手順4・5を「重要」としている理由

この2つは、**やらなくてもサイトは普通に表示されます。** だから気づきません。

しかし、

- 手順4を飛ばすと、**SNSで共有されたときにカード画像が出ません**。市民に広まるきっかけを失います
- 手順5を飛ばすと、**検索エンジンに古いアドレスを教え続けます**。検索結果に出にくくなります

## STEP 1: Supabase クラウドプロジェクトの作成

### 1-1. アカウント登録・プロジェクト作成

1. https://supabase.com にアクセスし、GitHubアカウント（`tee753-byte`）でサインアップ・ログイン
2. 「New Project」
3. 設定値
   - **Name**: `mirai-gikai-fukutsu`
   - **Database Password**: 強いパスワードを生成し、必ず控えておく（後で使う）
   - **Region**: `Northeast Asia (Tokyo)`
4. 「Create new project」（3〜5分待つ）

### 1-2. 接続情報を控える

作成後、以下を控えます（Settings > API）。

| 項目 | 場所 |
|---|---|
| Project URL | Settings > API > Project URL |
| anon key | Settings > API > Project API Keys > anon public |
| service_role key | Settings > API > Project API Keys > service_role（**秘密。人に見せない**） |

### 1-3. マイグレーションの適用

ローカルのターミナル（PowerShell、`mirai-gikai-fukutsu` フォルダ）で実施します。

```powershell
npx supabase login
npx supabase link --project-ref <上で控えたproject-ref>
npx supabase db push
```

- `project-ref` は Project URL の `https://<project-ref>.supabase.co` の部分
- `supabase login` はブラウザが開くのでSupabaseアカウントで認可する

### 1-4. `.env.production` の作成

`.env.production.example` をコピーして `.env.production` を作成し、1-2で控えた値を入れます（このファイルは `.gitignore` 対象なのでコミットされません）。

```powershell
Copy-Item .env.production.example .env.production
```

`.env.production` の中身:

```
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<service_role key>
NEXT_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon key>
```

### 1-5. 本番データの投入

福津市の実データのみを入れます（AIチャットのデモデータは除外）。

```powershell
$env:SEED_INCLUDE_DEMO_DATA = "false"
dotenv -e .env.production -- pnpm --filter @mirai-gikai/seed seed
Remove-Item Env:\SEED_INCLUDE_DEMO_DATA
```

実行後、ログの最後に `🎉 Database seeding completed successfully!` と出ればOKです。`Interview Config: 0` になっていることを確認してください（0であればAIチャットのデモデータが入っていない証拠です）。

> **確認**: Supabaseダッシュボード > Table Editor で `bills` テーブルなどにデータが入っていることを目視確認する。

## 既知の論点・保留事項

- **`ADMIN_URL` 未設定の影響**: `/preview/bills/...` という内部プレビュー画面でのみ使われる値で、通常の閲覧導線には影響しません。山本議員に見てもらう範囲では気にしなくて大丈夫です。
- **画像素材**（OGP・ロゴ・PWAアイコン）は福岡市版のままの可能性があります。山本議員お一人への限定公開であれば優先度は低いですが、気になる場合は差し替えてください。
- **議案書PDFの再配布可否**は未確認のままです（[立ち上げ設計書](20260730_1200_福津版立ち上げ設計書.md) 8-1参照）。今回のデータ投入では議案書PDFそのものは掲載していないので問題ありませんが、今後PDFを掲載する際は必ず確認を取ってから行ってください。
